## 🚀 How to Use This Curriculum

### For Teachers:

1. **Read LESSON_PLAN.md first** - Get overview
2. **Review COMPLETE_LESSON_GUIDE.md** - Complete reference
3. **Print QUICK_REFERENCE.md** - Give to students
4. **Convert LESSON_DOCUMENTATION_FOR_WORD.txt to a Word file** for official documentation
5. **Start with Lesson 01** - Upload to student robots
6. **Progress through lessons in order** - Each builds on previous

### For Students:

1. **Open Lesson_01_Forward_Movement.ino** in Arduino IDE
2. **Read the lesson header** - understand what you'll learn
3. **Upload to your robot** - watch it move!
4. **Try the challenge** - modify and experiment
5. **Move to next lesson** when complete

### Converting to Microsoft Word:

1. **Open LESSON_DOCUMENTATION_FOR_WORD.txt**
2. **Copy all content**
3. **Paste into Microsoft Word**
4. **Apply styles** (Heading 1, Heading 2, etc.)
5. **Add page breaks** between sections as needed
6. **Format to your preferences**
