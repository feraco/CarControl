INTRODUCTION
------------
This comprehensive robotics curriculum teaches programming and robotics
from absolute beginner to autonomous robot design. Students start by
making the robot move forward and progress to creating fully autonomous
robots that navigate, avoid obstacles, follow lines, and complete missions.

Total Time: 20-24 hours of instruction
Grade Level: Middle School through High School  
Prerequisites: None - designed for complete beginners
Platform: Arduino-compatible robot car with sensors

LEARNING PROGRESSION
--------------------
Module 1: Linear Motion (3 lessons, ~4 hours)
  - Learn basic movement: forward and backward
  - Understand code structure (setup and loop)
  - Practice precision and planning

Module 2: Rotational Motion (3 lessons, ~5 hours)
  - Master turning left and right
  - Create shapes and patterns
  - Navigate waypoints

Module 3: Ultrasonic Sensing (2 lessons, ~3 hours)
  - Understand distance sensors
  - Scan the environment
  - Make decisions based on sensor data

Module 4: Servo Control (2 lessons, ~3 hours)
  - Control servo motors
  - Operate the robot claw
  - Combine sensing and movement

Module 5: Obstacle Courses (2 lessons, ~3 hours)
  - Navigate complex environments
  - Implement avoidance algorithms
  - Handle stuck situations

Module 6: Line Following (2 lessons, ~4 hours)
  - Understand IR line sensors
  - Implement line-following algorithms
  - Handle curves and intersections

Module 7: Autonomous Design (2 lessons, ~4 hours)
  - Combine all skills
  - Create state machines
  - Design complete autonomous missions

PART 2: COMMAND REFERENCE FOR BEGINNERS
=============================================================================

This section explains every command in simple terms for students who
have never programmed before.

-----------------------------------------------------------------------------
MOVEMENT COMMANDS
-----------------------------------------------------------------------------

car.moveForward(speed, duration)
--------------------------------
What it does:
  Makes the robot drive forward in a straight line

How it works:
  Both motors spin forward at the same speed, making the wheels roll ahead

Parameters:
  speed - How fast to go (0 to 255)
    0 = stopped
    100 = slow/gentle
    180 = medium/normal
    255 = maximum speed
    
  duration - How long to move in milliseconds
    1000 = 1 second
    2000 = 2 seconds
    500 = half a second

Example:
  car.moveForward(150, 2000);
  This means: Move forward at medium speed for 2 seconds

When to use it:
  - Going straight
  - Approaching an object
  - Following a path

Common beginner mistakes:
  - Forgetting the semicolon at the end
  - Using speed greater than 255
  - Confusing duration (milliseconds not seconds)

---

car.moveBackward(speed, duration)
---------------------------------
What it does:
  Makes the robot drive backward (in reverse)

How it works:
  Both motors spin backward, like a car in reverse gear

Parameters:
  Same as moveForward

Example:
  car.moveBackward(120, 1000);
  This means: Back up slowly for 1 second

When to use it:
  - Backing away from obstacles
  - Returning to a previous position
  - Parking maneuvers

---

car.turnLeft(speed, duration)
-----------------------------
What it does:
  Makes the robot spin/turn to the left (counterclockwise)

How it works:
  Right motor spins FORWARD
  Left motor spins BACKWARD
  This makes the robot spin in place to the left

Parameters:
  speed - How fast to turn (0-255)
  duration - How long to turn (longer = bigger turn angle)
    Approximately:
    250ms = 45 degrees (small turn)
    500ms = 90 degrees (quarter turn)
    1000ms = 180 degrees (turn around)

Example:
  car.turnLeft(150, 500);
  This means: Turn left 90 degrees at medium speed

When to use it:
  - Changing direction
  - Avoiding obstacles on the right
  - Making shapes (squares, hexagons)

Important note:
  The exact angle depends on your robot! You may need to experiment
  to find the right duration for a 90-degree turn on YOUR robot.

---

car.turnRight(speed, duration)
------------------------------
What it does:
  Makes the robot spin/turn to the right (clockwise)

How it works:
  Left motor spins FORWARD
  Right motor spins BACKWARD
  This makes the robot spin in place to the right

Parameters:
  Same as turnLeft

Example:
  car.turnRight(150, 500);
  This means: Turn right 90 degrees

---

car.turnAround()
---------------
What it does:
  Makes the robot turn 180 degrees (half circle)

How it works:
  Automatically turns left for the right amount of time to spin halfway around

Parameters:
  None - it's automatic!

Example:
  car.turnAround();
  This means: Turn to face the opposite direction

When to use it:
  - Going back the way you came
  - Escaping dead ends
  - Changing direction completely

---

car.stopMotors()
---------------
What it does:
  Stops all robot movement immediately

How it works:
  Cuts power to both motors

Parameters:
  None

Example:
  car.stopMotors();
  This means: Stop right now!

When to use it:
  - End of a movement sequence
  - When obstacle detected
  - Emergency stop
  - Before changing direction

-----------------------------------------------------------------------------
SENSOR COMMANDS
-----------------------------------------------------------------------------

car.getDistanceToObstacle()
---------------------------
What it does:
  Measures how far away the nearest object is in front of the robot

How it works:
  1. Sends out an ultrasonic sound (too high for humans to hear)
  2. Listens for the echo bouncing back
  3. Calculates distance based on how long the echo took
  4. Returns distance in centimeters

Returns:
  A number representing distance in centimeters
  10 = object is 10cm away (very close!)
  50 = object is 50cm away (medium distance)
  100+ = object is far away or not detected

Example:
  int distance = car.getDistanceToObstacle();
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  
  if(distance < 20) {
    Serial.println("Too close! Stopping!");
    car.stopMotors();
  }

When to use it:
  - Before moving forward
  - To avoid hitting walls
  - To find objects
  - To stop at the right distance

---

car.getCenterDistance()
car.getLeftDistance()
car.getRightDistance()
----------------------
What they do:
  Point sensor in a direction and measure distance

getCenterDistance() - Points straight ahead and measures
getLeftDistance() - Points to the left and measures
getRightDistance() - Points to the right and measures

How they work:
  Moves the sensor servo to the correct angle, waits for it to
  stabilize, then measures distance

Example of scanning:
  int left = car.getLeftDistance();
  int center = car.getCenterDistance();
  int right = car.getRightDistance();
  
  if(center > left && center > right) {
    Serial.println("Go straight!");
  } else if(left > right) {
    Serial.println("Turn left!");
  } else {
    Serial.println("Turn right!");
  }

When to use them:
  - Finding the clearest path
  - Scanning for obstacles  
  - Deciding which way to turn

-----------------------------------------------------------------------------
SERVO COMMANDS
-----------------------------------------------------------------------------

car.attachSensorServo(pin)
-------------------------
What it does:
  Connects the sensor servo motor to the Arduino

Parameters:
  pin - Which Arduino pin the servo is connected to (usually 10)

Example:
  void setup() {
    car.attachSensorServo(10);
  }

When to use it:
  ONCE in setup() before using any servo commands

Important:
  You MUST call this before using lookLeft(), lookRight(), or centerServo()

---

car.lookLeft()
car.lookRight()
car.centerServo()
-----------------
What they do:
  Turn the ultrasonic sensor to look in different directions

lookLeft() - Turns sensor to 0 degrees (left position)
lookRight() - Turns sensor to 180 degrees (right position)
centerServo() - Points sensor at 90 degrees (straight ahead)

Example:
  car.lookLeft();
  delay(500);  // IMPORTANT: Wait for servo to move!
  // Now you can measure distance to the left

Important:
  Always add a delay(500) after moving the servo to give it
  time to reach the position before measuring!

Always recenter:
  car.centerServo();  // Point forward when done scanning

---

car.attachClaw(pin)
------------------
What it does:
  Connects the claw servo motor to the Arduino

Parameters:
  pin - Which Arduino pin the claw is connected to (usually 11)

Example:
  void setup() {
    car.attachClaw(11);
  }

---

car.openClaw()
car.closeClaw()
--------------
What they do:
  Control the robot's grabber claw

openClaw() - Opens the claw to release or prepare to grab
closeClaw() - Closes the claw to grab an object

Example grab sequence:
  car.openClaw();              // 1. Open claw
  delay(1000);
  car.moveForward(100, 800);   // 2. Approach object  
  delay(500);
  car.closeClaw();             // 3. Grab object
  delay(1500);
  car.moveBackward(100, 500);  // 4. Back away with object

Important:
  Add delays after claw commands to give the servo time to move!

-----------------------------------------------------------------------------
LINE SENSOR COMMANDS
-----------------------------------------------------------------------------

car.initLineSensors()
--------------------
What it does:
  Sets up the line sensors for use

Example:
  void setup() {
    car.initLineSensors();
  }

When to use it:
  ONCE in setup() before reading line sensors

---

car.getLineSensorLeft()
car.getLineSensorMiddle()
car.getLineSensorRight()
------------------------
What they do:
  Read the line sensor values

Returns:
  A number from 0 to 1023
  LOW (0-300) = On a BLACK line (dark, absorbs light)
  HIGH (700-1023) = On WHITE surface (bright, reflects light)
  MEDIUM (300-700) = Edge of line or gray surface

Example:
  int leftValue = car.getLineSensorLeft();
  Serial.print("Left sensor: ");
  Serial.println(leftValue);
  
  if(leftValue < 500) {
    Serial.println("On black line!");
  } else {
    Serial.println("On white surface");
  }

When to use them:
  - Detecting black lines on white surfaces
  - Line following algorithms
  - Finding intersections

---

car.followLine(threshold)
------------------------
What it does:
  Makes the robot follow a black line automatically

Parameters:
  threshold - Value to distinguish black from white (usually 500)
    Values BELOW threshold = on the line (black)
    Values ABOVE threshold = off the line (white)

How it works:
  - If center sensor sees line → go straight
  - If left sensor sees line → turn left
  - If right sensor sees line → turn right

Example:
  void loop() {
    car.followLine(500);
    delay(50);
  }

When to use it:
  In your loop() function to continuously follow a line

Calibration:
  You may need to adjust the threshold (500) based on your
  lighting and surface. Print sensor values to find the right number!

LESSON 01: First Steps - Moving Forward
-----------------------------------------------------------------------------
Time: 45 minutes
File: Lesson_01_Forward_Movement.ino

Objectives:
- Set up the Arduino programming environment
- Learn the basic code structure (setup and loop functions)
- Make the robot move forward
- Control movement speed and duration
- Use Serial.println() for debugging

Commands Taught:
- car.moveForward(speed, duration)
- car.stopMotors()
- Serial.println()
- delay()

What Students Learn:
This is the first program! Students learn that code has two parts:
  - setup(): Runs once when robot starts
  - loop(): Runs over and over forever

They learn to control the robot's speed (like a gas pedal, 0-255)
and duration (how long to move in milliseconds).

Challenge:
Students modify the code to make their robot move forward THREE
different distances:
  1. Short distance (0.5 seconds)
  2. Medium distance (1.5 seconds)
  3. Long distance (3 seconds)

Bonus: Make the robot spell the letter "I" by moving forward,
stopping, then forward again.

Assessment:
- Can student upload and run the program?
- Can student modify speed and duration values?
- Can student explain what milliseconds are?
- Did student complete the challenge?

LESSON 02: Going Backward
-----------------------------------------------------------------------------
Time: 30 minutes
File: Lesson_02_Backward_Movement.ino

Objectives:
- Make the robot move backward
- Combine forward and backward movements
- Create movement sequences with timing
- Understand motor direction control

Commands Taught:
- car.moveBackward(speed, duration)

What Students Learn:
Moving backward is just like forward, but motors spin the opposite
direction (like a car in reverse). Students learn to sequence multiple
movements with delays between them.

Challenge: The Robot Dance
Create a "dance" routine using forward and backward movements.
Requirements:
- At least 6 movements
- Use 3 different speeds
- Use different durations
- Create rhythm with delays

Bonus Challenges:
1. Spell the letter "H" (forward, back to start, forward again)
2. Make a dance that lasts exactly 10 seconds
3. Add Serial messages to name each dance move

Assessment:
- Can student sequence multiple movements?
- Does student understand timing with delay()?
- Is the dance creative and well-timed?

LESSON 03: Linear Motion Challenge
-----------------------------------------------------------------------------
Time: 60 minutes
File: Lesson_03_Linear_Motion_Challenge.ino

Objectives:
- Master forward and backward movement
- Plan multi-step movement sequences
- Navigate to specific positions
- Understand precision in programming

Commands Review:
- moveForward(), moveBackward(), stopMotors(), delay()

What Students Learn:
Linear motion means moving in straight lines. By combining movements

Main Challenge: The Obstacle Course

Requirements:

Bonus Challenges:
1. "Park" by approaching finish line fast, then slow for precision
2. Add countdown (3...2...1...GO!) before starting
3. Create a delivery mission with multiple stops

Assessment:
- Can student plan multi-step sequences?
- Does robot navigate accurately?
- Did student use Serial messages effectively?

LESSON 04: Turning Left and Right
-----------------------------------------------------------------------------
Time: 45 minutes
File: Lesson_04_Basic_Turning.ino

Objectives:
- Understand how turning works (motors spinning opposite directions)
- Make the robot turn left and right
- Combine turning with forward movement
- Create basic navigation patterns

Commands Taught:
- car.turnLeft(speed, duration)
- car.turnRight(speed, duration)

What Students Learn:
Turning works differently than forward movement. For turning:
  - Left turn: Right motor forward, Left motor backward
  - Right turn: Left motor forward, Right motor backward

This makes the robot spin in place! Duration controls the angle:
  ~250ms = 45 degrees
  ~500ms = 90 degrees
  ~1000ms = 180 degrees
(Students must experiment to find exact values for THEIR robot)

Main Challenge: Make a Square
Program the robot to drive in a perfect square pattern:
- 4 equal sides
- 4 right-angle (90°) turns
- End at start position facing same direction

Requirements:
- All forward movements same duration
- All turns same duration
- Use Serial messages to label each side

Bonus Challenges:
1. Make a triangle (3 sides, 120-degree turns)
2. Make a rectangle (2 long sides, 2 short sides)
3. Make the robot drive a square twice
4. Add pauses at each corner

Assessment:
- Does robot complete the square?
- Are turns approximately 90 degrees?
- Can student explain how turning works?

LESSON 05: Advanced Rotation
-----------------------------------------------------------------------------
Time: 60 minutes
File: Lesson_05_Advanced_Rotation.ino

Objectives:
- Make precise angle turns
- Create complex shapes (hexagon, octagon)
- Understand angle mathematics
- Use for loops for patterns

Commands Taught:
- car.turnAround()
- for loops for repeated patterns

What Students Learn:
Math connection! Turn angle for any regular shape:
  360 ÷ number of sides = turn angle
  - Triangle: 360 ÷ 3 = 120 degrees
  - Square: 360 ÷ 4 = 90 degrees
  - Hexagon: 360 ÷ 6 = 60 degrees
  - Octagon: 360 ÷ 8 = 45 degrees

Students learn to use for loops to repeat patterns:
  for(int i = 0; i < 6; i++) {
    // This runs 6 times for a hexagon
  }

Main Challenge: Create an Octagon
Make the robot drive in a perfect octagon (8 equal sides)
Requirements:
- Use a for loop to repeat 8 times
- Calculate 45-degree turn duration
- Print which side you're on (1-8)
- End at start position

Bonus Challenges:
1. Pentagon (5 sides, 72-degree turns)
2. Create drawShape(numSides) function
3. Draw octagon, turn around, draw another octagon
4. Create "flower pattern" (8 squares in a circle)

Assessment:
- Does student understand the math?
- Can student use for loops effectively?
- Did robot complete the octagon?
- Can student modify for different shapes?

Assessment:

HARDWARE SETUP
--------------
Required Components:
- Arduino-compatible robot car
- TB6612FNG motor driver
- 2x DC motors
- HC-SR04 ultrasonic sensor
- 3x IR line sensors
- 2x Servo motors (sensor pan and claw)
- Robot claw gripper
- RGB LED (WS2812)
- Buzzer (optional)
- Battery pack (7.4V recommended)

Pin Configuration:
  Motors:
    PWMA: Pin 5
    PWMB: Pin 6
    AIN: Pin 7
    BIN: Pin 8
    STBY: Pin 3

  Ultrasonic:
    TRIG: Pin 13
    ECHO: Pin 12

  Servos:
    Sensor Servo: Pin 10
    Claw Servo: Pin 11

  Line Sensors:
    Left: A2
    Middle: A1
    Right: A0

  Other:
    RGB LED: Pin 4
    Buzzer: Pin 11
    Battery: Pin A3

TROUBLESHOOTING GUIDE
---------------------

Problem: Robot doesn't move
Solutions:
- Check battery charge
- Verify car.setup() is called in void setup()
- Check motor connections
- Verify code uploaded successfully

Problem: Servo doesn't work
Solutions:
- Did you call attachSensorServo(10) or attachClaw(11)?
- Add delay() after servo commands
- Check servo connection to correct pin
- Verify servo has power

Problem: Sensor values seem wrong
Solutions:
- Calibrate for your environment
- Print values to see what sensor actually reads
- Check lighting conditions
- Adjust threshold values

Problem: Code uploads but robot does nothing
Solutions:
- Check if code is in setup() or loop()
- Setup runs once, loop runs forever
- Add Serial.println() to debug
- Check battery power

Problem: Robot turns wrong amount
Solutions:
- Experiment with duration values
- Each robot is slightly different
- Surface affects turn radius
- Adjust turn duration for your robot

Problem: Line following doesn't work
Solutions:
- Calibrate threshold value
- Print sensor values to find right threshold
- Check lighting (bright overhead light best)
- Verify line is 1.5-2cm wide black tape
- Make sure sensors are close to ground

TEACHING TIPS
-------------

For Complete Beginners:
1. Start with modification, not creation
   - Give them working code
   - Ask them to change ONE thing
   - Example: "Change 150 to 200 and see what happens"

2. Use physical analogies
   - delay() = counting "Mississippi"
   - Speed = gas pedal
   - Sensors = your eyes

3. Make it concrete
   - Print everything with Serial
   - Use real measurements (cm, not ms)
   - Physical markers and tape

4. Scaffold heavily
   - Week 1-2: Modify existing code
   - Week 3-4: Fill in blanks
   - Week 5+: Write from scratch

Common Mistakes to Watch For:
- Forgetting semicolons
- Confusing setup() and loop()
- Not waiting after servo commands
- Using wrong units (seconds vs milliseconds)

Engagement Strategies:
- Robot races (who can navigate fastest?)
- Design challenges (most creative solution)
- Pair programming (driver/navigator)
- Robot demonstrations to other classes
